# R Fundamental and Statistical Analysis for Beginners

**WSQ course code:** TGS-2019504058  
**Version:** v15.0 · 20 August 2026  
**Duration:** 2 days · 16 hours

Source-aligned WSQ courseware for beginner-to-intermediate R programming and statistical analysis. The package preserves the useful coverage of the legacy v14 deck and original exercises while rebuilding the visual design, labs and learner documents to current Tertiary Infotech Academy standards.

## Courseware

- Trainer slide deck: `R-Fundamental-and-Statistical-Analysis-for-Beginners-v15.0.pptx` (150 slides)
- Learner slide PDF: `R-Fundamental-and-Statistical-Analysis-for-Beginners-v15.0.pdf`
- Learner Guide: `LG-R-Fundamental-and-Statistical-Analysis-for-Beginners-v15.0.docx` and PDF
- Lesson Plan: `LP-R-Fundamental-and-Statistical-Analysis-for-Beginners-v15.0.docx` and PDF
- Hands-on labs: `labs/` — twelve self-contained folders, each with R scripts and an Excel workbook

## Topics

1. Getting Started in R
2. Data Types
3. R Packages and Data I/O
4. Data Visualisation
5. R Programming
6. Statistical Analysis with R

## Lab workflow

Open a lab folder in RStudio, follow its `README.pdf` or `README.md`, run the numbered R script, then run `verify.R`. Record evidence in `lab-workbook.xlsx`.

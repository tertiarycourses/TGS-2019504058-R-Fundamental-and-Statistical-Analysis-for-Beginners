## About the course

The package preserves the useful coverage of the legacy v14 deck and original exercises while rebuilding the visual design, labs and learner documents to current Tertiary Infotech Academy standards.

## Learning outcomes

1. Install R and R Studio IDE.
2. Understand and use R data types.
3. Understand and use R packages and datasets.
4. Perform data visualisation in R.
5. Understand and code R programming language.
6. Understand and use statistical methods in R.

## Topics covered

1. Getting Started in R
2. Data Types
3. R Packages and Data I/O
4. Data Visualisation
5. R Programming
6. Statistical Analysis with R

## Labs

Twelve self-contained folders under [`labs/`](labs/), each with R scripts and an Excel workbook. Open a lab folder in RStudio, follow its `README.pdf` or `README.md`, run the numbered R script, then run `verify.R`, and record evidence in `lab-workbook.xlsx`.

1. [Your First Reproducible R Script](labs/lab-01-rstudio-first-script/README.md)
2. [Help, Objects and Session Diagnostics](labs/lab-02-help-session-diagnostics/README.md)
3. [Vectors, Indexing and Missing Values](labs/lab-03-vectors-indexing-missing/README.md)
4. [Data Structures and Factors](labs/lab-04-structures-factors/README.md)
5. [Packages and Built-in Datasets](labs/lab-05-packages-built-in-data/README.md)
6. [Import, Validate and Export Weather Data](labs/lab-06-import-validate-export/README.md)
7. [Base R Chart Selection](labs/lab-07-base-r-chart-selection/README.md)
8. [Compare Distributions with Boxplots](labs/lab-08-distribution-comparison/README.md)
9. [Conditions, Loops, next and break](labs/lab-09-conditions-loops/README.md)
10. [Build and Test Reusable Functions](labs/lab-10-reusable-functions/README.md)
11. [Descriptive Statistics, Correlation and Regression](labs/lab-11-descriptive-correlation-regression/README.md)
12. [Hypothesis Testing and ANOVA Capstone](labs/lab-12-hypothesis-anova-capstone/README.md)
